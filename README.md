# tbb_ra8_audio_dsp_ra8d1_interposer
Audio DSP TBB interposer for use with EK-RA8D1

This TBB Interposer connects to the pin headers EK-RA8D1, and acts as a bridge to the TBB Audio DSP board.

## Toolchain
- Altium Designer 26.x
